# STAPPS

A starter GitHub project for rapid development.

## Getting started

### Prerequisites

- Python 3.10+
- Git

### Installation

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
.venv\Scripts\activate     # Windows
pip install -r requirements.txt
```

### Run the project

```bash
python -m pip install -r requirements.txt
```
